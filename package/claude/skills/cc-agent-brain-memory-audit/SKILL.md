# CC Agent Brain Memory Audit

Use when:

- many new session notes have accumulated
- the user says the assistant forgot something
- the assistant finds conflicting project information
- memory files are growing too large

## Check

1. Duplicate preferences
2. Conflicting project status
3. Stale tasks
4. Old decisions that may no longer apply
5. Important Wiki pages not reflected in memory index
6. Sensitive information accidentally stored in memory

## Output

Create a concise audit report in `wiki/tasks/memory-audit-YYYY-MM-DD.md`.
