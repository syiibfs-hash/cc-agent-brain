# Memory Design

## Principle

Wiki saves context. Memory saves compressed indexes.

## Wiki-first flow

```text
prompt / task / file work
↓
wiki/sessions
↓
wiki/projects / wiki/materials / wiki/decisions
↓
memory/MEMORY.md and related memory files
```

## What belongs in Wiki

- session notes
- project progress
- decisions and rationale
- reusable materials
- prompts
- concepts
- task records

## What belongs in Memory

- user and assistant names
- durable response preferences
- active project index
- stable long-term facts
- retrieval policy

## What does not belong in Memory

- raw transcripts
- one-off tasks
- secrets
- uncertain guesses
- stale or temporary information
